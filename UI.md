# Native UI

Use SwiftUI views under native-ios/UI and the existing styles in RobocopTheme.swift. Keep Queue, Rewards, and Settings consistent with the muted QueueChrome colors, typography, spacing, and compact actions.

- [Chrome conventions](native-ios/Docs/CHROME.md)
- [Live Activity design](native-ios/Docs/LIVE-ACTIVITY-DESIGN.md)
- [Native/legacy parity record](native-ios/Docs/PARITY.md)
- [Device and accessibility checks](native-ios/Docs/DEVICE-ACCESSIBILITY-CHECKS.md)

Preserve iPad layouts, Dynamic Type, accessibility identifiers, Reduce Motion support, and account/visitor behavior when restyling. Do not change inactive tabs merely for visual uniformity.
